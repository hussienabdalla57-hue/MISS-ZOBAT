# منظومة إدارة وحسابات الميس (نسخة تعمل بدون إنترنت)

## الرفع على GitHub Pages
1. أنشئ مستودعًا جديدًا (New repository) على GitHub.
2. اضغط Add file ثم Upload files، وارفع كل الملفات: `index.html`، `sw.js`، `manifest.webmanifest`، `icon.svg`، `icon-192.png`، `icon-512.png`، `.nojekyll`، ومجلد `fonts` (اختياري).
3. من Settings ثم Pages: اختر Deploy from a branch، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقائق يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`
5. افتح الرابط مرة واحدة والإنترنت شغال. بعدها يعمل بدون إنترنت.
   - على الموبايل: من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

## بدون رفع
افتح `index.html` مباشرة من المتصفح على اللاب. على الموبايل يفضل الرابط، لأن بعض المتصفحات تمنع حفظ البيانات للملفات المحلية (سيظهر تنبيه في شاشة الدخول).

## ملاحظات
- البيانات تُحفظ على الجهاز نفسه، ولكل جهاز ومتصفح بياناته. انقلها بين الأجهزة من الإعدادات ثم النسخ الاحتياطي.
- تسجيل الدخول قفل محلي على الجهاز وليس حماية كاملة. إذا نسيت كلمة المرور فلن تفتح البيانات إلا بمسح بيانات الموقع، وهذا يمسحها، فاحتفظ بنسخة احتياطية.
- لتحديث النسخة: استبدل `index.html` في المستودع، ثم افتح الموقع مرتين ليظهر التحديث.
- الكشوف تستخدم خط PT Bold Heading إن كان مثبتًا على الجهاز، وإلا يُستخدم خط بديل.
